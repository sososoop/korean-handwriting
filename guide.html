받아쓰기 · 따라쓰기 · 글씨 연습지를 몇 번의 클릭으로 만들어 인쇄하세요.

웹앱 바로 열기 →
01

30초 빠른 시작

STEP 1

연습할 글 입력

왼쪽 연습할 글 칸에 문장이나 낱말을 한 줄에 하나씩 적어요.

STEP 2

글꼴 · 칸 · 모드 고르기

글꼴, 가로·세로 칸 수, 안내선, 글씨 모드를 학생 수준에 맞춰 조절해요.

STEP 3

미리보기 확인

오른쪽에 A4 연습지가 실시간으로 그려져요. 바뀐 설정이 바로 반영됩니다.

STEP 4

인쇄 / PDF 저장

인쇄 / PDF 저장 버튼을 눌러 종이로 뽑거나 PDF로 저장해요.

02

설정 한눈에 보기

연습할 글
입력한 줄이 가로 칸 수보다 길면 자동으로 다음 줄로 넘어가요. 빈 줄을 넣으면 연습지에도 빈 줄이 생깁니다.
글꼴
받아쓰기·손글씨 글꼴 12종. 정자체 연습엔 학교안심 받아쓰기, 흥미 유도엔 손글씨 글꼴을 써요.
칸 수
가로 칸(한 줄 글자 수)과 세로 줄(한 페이지 줄 수)을 ± 버튼으로 조절. 칸 크기는 A4에 맞춰 자동 계산돼요.
글자 크기
칸 대비 글자 비율(40~85%). 저학년은 크게, 문장 연습은 작게. 기본 62%.
안내선
없음십자십자+네모십자+마름모격자(米) — 아래에서 미리보기로 확인하세요.
글씨 모드
회색 따라쓰기검은 글씨빈칸 연습 3가지 연습 방식.
용지 방향
A4 세로(짧은 낱말) / 가로(문장 여러 줄). 기본은 가로.
부가 옵션
공백 제거(띄어쓰기 없이 낱글자) · 줄바꿈 무시(한 흐름으로 이어붙이기) · 빈 줄 추가(글자 줄 아래 직접 쓰는 칸).

05

바로 쓰는 활용 레시피

받아쓰기 연습지

  1. 받아쓰기 문장을 한 줄에 하나씩 입력
  2. 글꼴 학교안심 받아쓰기
  3. 글씨 모드 회색 따라쓰기 또는 검은 글씨
  4. 글자 줄 아래 빈 줄 추가 켜기 → 따라쓰고 스스로 한 번 더

낱글자 쓰기 연습지

  1. 연습할 글자 입력
  2. 가로 칸 수를 적게 → 칸이 커져요
  3. 안내선 십자+네모 또는 격자(米)
  4. 글씨 모드 회색 따라쓰기

빈칸 평가용 연습지

  1. 연습할 글을 넣어 칸 수·페이지 수 먼저 확인
  2. 글씨 모드 빈칸 연습으로 변경
  3. 인쇄 또는 PDF로 저장
06

인쇄 · PDF 저장 체크리스트

  • 용지 크기 — A4
  • 방향 — 웹앱에서 고른 방향과 동일하게(가로/세로)
  • 여백 — 기본 또는 없음
  • 배율 — 100% 권장
  • 배경 그래픽 — 안내선이 안 보이면 반드시 켜기
  • PDF 저장 — 프린터 목록에서 ‘PDF로 저장’ 선택
07

자주 묻는 질문

안내선이 인쇄·PDF에서 흐리게 나와요
인쇄 창에서 배경 그래픽 옵션을 켜 보세요. 브라우저·프린터 설정에 따라 안내선 출력이 달라질 수 있어요.
글자가 칸에서 너무 커 보여요
글자 크기 값을 낮추거나, 가로 칸·세로 줄 수를 줄여 칸을 크게 만들어 보세요.
한 페이지에 내용이 너무 많이 들어가요
세로 줄 수를 줄이면 한 페이지 줄 수가 줄고, 넘치는 내용은 다음 페이지로 자동 분할돼요.
띄어쓰기 칸이 비어 있어요
띄어쓰기는 빈칸으로 표시돼요. 띄어쓰기 없이 글자만 연습하려면 공백 제거를 켜세요.
처음 설정으로 되돌리고 싶어요
기본값으로 버튼을 누르면 됩니다. 기본값: 학교안심 받아쓰기 · 62% · 가로 14칸 · 세로 10줄 · 십자 · 회색 따라쓰기 · 가로 방향 · 빈 줄 추가 켜짐.
